Build order

  1. Two-mode menu skeleton
    Mode → Category → Item, existing actions rebucketed, new ones stubbed
    Shipped
  2. Set size + set goal (bench)
    runtime arena bounds + goal presets + BT commands · arena framed in the app
    Shipped
  3. Sensor threshold calibration
    the EEPROM config slot is now built — magic/version/length/checksum at address 512, written then read back, landed with the gyro-scale work. Thresholds become fields in the same block: bump the version and an older block still loads with the new field defaulted. What remains is the THR command and the guided calibration flow in the app
    Next
  4. Turn tuning
    live tuner shipped · gyro scale calibrated (720° spin) · arc tuning in progress
    Shipped
  5. Integrated-turn primitive + toggles
    wire the arc into search & the wall follower
    Then
  6. Non-blocking sensor read
    shipped as a five-state sampler ticked from the 1 kHz ISR — DARK (four ambients) → SL → FL → FR → SR, one state per tick, so a full ambient-subtracted set lands every 5 ms and the ~218 µs of settle busy-wait becomes "next tick". Emitters are switched at the end of a tick and sampled at the start of the next, giving a ~1 ms settle for free (20× the old count). Thread context always wins the ADC — taking the lock parks the sampler — so the main-loop battery read that feeds the low-battery cutoff can never be stalled by it. Opt-in (S); the blocking read stays the default until bench-proven. Superseded by the G431 timer+DMA front end later
    Shipped
  7. Dead-end re-square
    after the 180, reverse into the dead-end wall to re-zero heading + longitudinal — free drift correction each dead end, reuses the start reverse move
    Then
  8. Diagonal navigation
    biggest rock — planner + 45° motion, last
    Later
  9. Native iPad companion app
    SwiftUI + Core Bluetooth · polished, shareable build — the web app is its prototype & protocol spec (Apple account in hand)
    Nice-to-have
